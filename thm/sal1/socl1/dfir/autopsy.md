# Workflow Overview

- Create/open the case for the data source you are investigating
- Select the data source you wish to analyse
- Configure the ingest modules to extract specific artifacts
- Review artifacts
- Create report
    
<br/>When creating a new case file from a data source, you must enter the following information:

- Case Name
- Base Directory
- Case Type
- Case files with a `.aut` file extension can also be imported by Autopsy.

# Data Sources

Autopsy can analyse various disk image formats:

- Raw Single (`.img`, `.dd`, `.raw`, `.bin`)
- Raw Split (`.001`, `.002`, `.aa`, `.ab`)
- EnCase (`.e01`, `.e02`)
- Virtual Machine (`.vmdk`, `.vhd`)

# Ingest Modules

Essentially plug-ins designed to analyse and retrieve specific info from the drive. Ingest modules can be enabled/disabled while adding a data source in Autopsy. Alternatively, they can be configured on pre-loaded disks by:

1. Open `Run Ingest Modules` by right-clicking the data source
2. Choose modules to implement and click on finish
3. Track progress

# User Interface
## Tree Viewer

- Data Sources: all data organised as it would be in normal Windows File Explorer
- Views: files organised based on file types
- Results: results from any ingest modules
- Tags: files or results which have been tagged
- Reports: reports generated by modules or by the analyst

## Result Viewer

Displays additional information about any selected volume/file/folder which has been selected from the Tree Viewer.

## Contents Viewer

Clicking any file/folder from the table tab will display additional info here:

- S (Score): shows a red exclamation point for a folder/file tagged as notable and a yellow triangle pointing downward for a folder/file tagged as suspicious. This can be done by the analyst or by a module.
- C (Comment): if a yellow page is visible here, it indicates there is a comment.
- O (Occurrence): indicates how many times the file/folder has been seen in previous cases.

## Keyword Search

In the top right, you can find keyword lists and keyword search to perform an AD-HOC keyword search.

## Data Sources Summary

Provides summarised info in nine different categories.

## Generate Report

Can create reports in multiple formats for re-analysis.
