# What Information Should be Collected?

- Sender email address
- Sender IP address
- Reverse lookup of sender IP address
- Recipient email address
- Reply-To email address (if applicable)
- Date/time
- Any URL links
- The name of any attachments
- The hash value of any attachments

# Email Header Analysis

- [MessageHeader](https://toolbox.googleapps.com/apps/messageheader/analyzeheader): tool provided by Google for analysing SMTP message headers.
- [Message Header Analyser](https://mha.azurewebsites.net/)
- [MailHeader](https://mailheader.org/)

# Email Body Analysis

- [URL Extractor](https://www.convertcsv.com/url-extractor.htm): can take raw HTML headers and output URLs contained.
