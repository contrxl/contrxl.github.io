# Reconnaissance

This is the act of discovering and collecting information on the system & victim. This is a planning phase. OSINT can be used for reconnaissance to collect information like company size, email addresses, phone numbers etc. Email harvesting can be used to obtain email addresses using various websites like:

- [TheHarvester](https://github.com/laramies/theHarvester)
- [Hunter.io](https://hunter.io/)
- [OSINT Framework](https://osintframework.com/)

# Weaponization

A weaponizer combines malware and an exploit into a single deliverable payload, this is usually generated by an automated tool or acquired from the DarkWeb. More sophisticated actors like APTs will write custom malware to use in this stage.

# Delivery

This phase is where a method of transmission is chosen, this can be (but is not limited to):

- Phishing Emails
- Distribution of Infected USB Sticks
- Watering Hole Attacks

# Exploitation

To access systems, an attacker needs to exploit a vulnerability. Attackers can use various methods to carry out exploitation:

- Victim triggers the exploit by opening the mail attachment or clicking a malicious link
- Using a zero-day exploit
- Exploiting software, hardware or people
- Attacker triggers a server-side exploit

# Installation

This is where the attacker establishes a persistent backdoor to allow them to repeatedly access a compromised system. Persistence can be achieved through:

- Installing a web shell on a webserver
- Installing a backdoor on a victim machine
- Creating or modifying Windows services
- Adding an entry to "Run keys" for the malicious payload in Registry/Startup

# Command & Control

C2 allows the C2 server to communicate with malware on the affected host. This allows the attacker to have full control of the victim machine. Common C2 channels are:

- HTTP and HTTPS 443 beaconing to help mask traffic
- DNS: affected machine makes DNS requests to an attackers DNS server

# Actions on Objectives/Exfiltration

Now that the attacker has hands-on access, they can:

- Collect user credentials
- Perform privilege escalation
- Internal reconnaissance
- Lateral movement through environment
- Collect and exfiltrate sensitive data
- Delete backups or shadow copies
- Overwrite or corrupt data
