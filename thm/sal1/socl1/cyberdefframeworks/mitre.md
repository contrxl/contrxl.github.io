# Basic Terminology

- APT: Advanced Persistent Threat
- TTP: Tactics, Techniques and Procedures
- ATT&CK: Adversarial Tactics, Techniques and Common Knowledge
- CAR: Cyber Analytics Repository
- D3FEND: Detection, Denial and Disruption Framework Empowering Network Defense
- AEP: ATT&CK Emulation Plans

# ATT&CK Framework

According to the website, the ATT&CK framework is: *"MITRE ATT&CK® is a globally-accessible knowledge base of adversary tactics and techniques based on real-world observations"*. The framework can be accessed here: [MITRE ATT&CK](https://attack.mitre.org/)

# CAR Knowledge Base

The official definition is: *"The MITRE Cyber Analytics Repository (CAR) is a knowledge base of analytics developed by MITRE based on the MITRE ATT&CK ®  adversary model. CAR defines a data model that is leveraged in its pseudocode representations but also includes implementations directly targeted at specific tools (e.g., Splunk, EQL) in its analytics. With respect to coverage, CAR is focused on providing a set of validated and well-explained analytics, in particular with regards to their operating theory and rationale."* The CAR knowledge base can be seen [here](https://car.mitre.org/).

# MITRE ENGAGE

MITRE engage can be found [here](https://engage.mitre.org/). MITRE Engage is considered an Adversary Engagement Approach, this is accomplished via Cyber Denial and Cyber Deception. Cyber denial prevents adversaries conducting operations and cyber deception intentionally misleads adversaries.

# MITRE D3FEND

MITRE D3FEND can be found [here](https://d3fend.mitre.org/). Per the website, this is *"A knowledge graph of cybersecurity countermeasures"*.
