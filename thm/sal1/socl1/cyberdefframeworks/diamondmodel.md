# Adversary

This is a person behind a cyberattack. This is any actor or organisation responsible for utilising a capability against a victim. An adversary operator is the hacker or person(s) conducting the intrusion. An adversary customer is the entity that stands to benefit from the activity conducted in the intrusion.

# Victim

This is the target of an adversary and can be an organisation, person, email address, IP address, domain etc. A victim personae is a person or organisation being targeted. A victim asset is the actual attack surface like systems, networks, emails and so on.

# Capability

The skill, tools and techniques used by the adversary. Highlights the adversary's TTPs. Capability capacity is all vulnerabilities and exposures that can be used. Adversary arsenal is a set of capabilities belong to an adversary.

# Infrastructure

This is the physical or logical interconnections used to deliver a capability or maintain control of a capability. Infrastructure can also be IP addresses, domain names, emails or malicious USBs. Type 1 infrastructure is controlled by an adversary and type 2 infrastructure is controlled by an intermediary.

# Event Meta Features

Six possible meta features can be added to the diamond model:

- Timestamp: date and time of the event occurring
- Phase: phases of intrusion, attack or breach.
- Result: results and post-conditions of an attack where they are known. These can be related to the CIA triad.
- Direction: helps describe host-based and network-based events.
- Methodology: allows analysts to describe the general classification of the intrusion
- Resources: every intrusion needs one or more external resources, for example; knowledge, software, hardware, information, funds.

# Social-Political Component

Describes the needs and the intent of the adversary.

# Technology Component

Technology meta-feature highlighting the relationship between core features: capability and infrastructure.
