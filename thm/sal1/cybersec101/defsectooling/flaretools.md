# Arsenal of Tools
## Reverse Engineering and Debugging

- Ghidra: NSA Open-Source reverse engineering suite.
- x64dbg: Open-source debugger for binaries in x64 and x32 formats.
- OllyDbg: Debugger for reverse engineering at assembly level.
- Radare2: Sophisticated open-source platform for reverse engineering.
- Binary Ninja: Tool for disassembling and decompiling binaries.
- PEiD: Packer, cryptor and compiler detection.

## Disassemblers and Decompilers

- CFF Explorer: PE designed to analyse and edit PE files.
- Hopper Disassembler: Debugger, disassembler and decompiler.
- RetDec: Open-source decompiler for machine code.

## Static and Dynamic Analysis

- Process Hacker: Sophisticated memory editor and process watcher.
- PEview: PE file viewer.
- Dependency Walker: Tool for displaying an executables DLL dependencies.
- DIE (Detect it Easy): Packer, compiler and cryptor detection tool.

## Forensics and Incident Response

- Volatility: RAM dump analysis framework.
- Rekall: Framework for memory forensics.
- FTK Imager: Disc image acquisition and analysis.

## Network Analysis

- WireShark: Network protocol analyser.
- Nmap: Vulnerability detection and network mapping.
- Netcat: Read and write data across networks.

## File Analysis

- FileInsight: Look through and edit binary files.
- Hex Fiend: Hex editor.
- HxD: Hex editor.

## Scripting and Automation

- Python
- PowerShell Empire

## SysInternals

- Autoruns: Show what executables are doing during bootup
- Process Explorer: Information about running processes.
- Process Monitor: Monitor and log real-time process activity.
