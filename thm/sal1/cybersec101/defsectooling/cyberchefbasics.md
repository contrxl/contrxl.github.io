# Interface

CyberChef has four main areas:

1. Operations: repository of all the operations which CyberChef is equipped to perform, these are meticulously categorised and offer various capabilities.
2. Recipe Area: allows you to select, arrange and fine-tune operations to suit your needs. This includes the ability to save, load and clear recipes.
3. Input Area: user-friendly space to input text or files for parsing. Allows creation of new input tabs, opening folders or files an input and clearing the input box.
4. Output Area: showcases processing results, presents outcomes of manipulations or transformations.
